What it is

One bot instead of ten tabs

Chomik was built to be all-in-one: instead of hopping between lookup sites, cipher tools and image editors, you run a command and get the result in your chat. You can think of it as a small OSINT toolkit that lives in Discord.

Data fetching

Information across platforms

Look things up without leaving the conversation.

  • Roblox profiles, avatars, previous names, groups, followers, friends and mutuals
  • Games, badges, gamepasses and sub-places, with ID resolving in both directions
  • YouTube, TikTok and Pinterest search, right in Discord
  • Report Roblox users and view report statistics
/user/game/badges/gamepasses/groups/names/mutuals/youtube

Crack the code

Stuck on a mysterious string of letters? Identify it, decode it, or just try everything.

  • Identify unknown ciphers, then decode or encode them
  • Find the live links an ID or string belongs to, and a site's known subdomains
  • Anagram and Nutrimatic solvers for word puzzles

Follow the trail

Most puzzles start with an account, a game or a name. Chomik helps you track the connections.

  • Resolve profiles, convert place IDs to universes and list a game's subplaces
  • Check previous usernames, groups, badges and mutual friends for hidden links
  • Pull text out of screenshots with OCR

Questions

Quick answers about Chomik.

Is Chomik really free?

Yes. It is free permanently and there are no paywalled features, now or later.

Can I add it to my server?

Chomik is currently a small bot for people the developer knows, and it is going public soon. If you want in early, ask in the support server.

How does it work?

The developer is happy to explain how Chomik operates. Join the support server and ask, nothing is kept secret.

How is it free?

Everything it uses is built on free services or free trials.

Something is broken, what do I do?

Check the status page first, then tell us in the support server.

Give Chomik a try

Add it to your server, or join the support server to see what it can do and ask anything about how it works.
